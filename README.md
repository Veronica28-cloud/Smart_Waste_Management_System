# Smart_Waste_Management_System
Smart Waste Management Platform: A civic-tech web app streamlining municipal waste workflows. Features user complaint registration, real-time ticket lifecycle tracking, automated pickup dispatching, and dynamic user profile dashboards to boost community recycling efficiency and operational transparency.
# ♻️ Smart Waste Management Platform (Green Garbage Management)

> **Awarded 3rd Place** at the **Programmix Hackathon 2025**, organized by the Programmix Club at BIT Mesra, Jaipur.

---

## Overview
The **Smart Waste Management Platform** is a civic-tech web application engineered to streamline municipal waste handling and complaint lifecycles. Built during a fast-paced 24-hour hackathon, the platform bridges the gap between citizens and municipal collection services by automating complaint logging, dispatch scheduling, and status tracking through an intuitive interface.

## Key Features
* **User Profile & Activity Hub:** Dynamic user profile dashboard displaying complaint submission history, credentials, and real-time status.
* **Automated Complaint Lifecycle:** Structured relational pipeline (`Submitted` ➔ `In-Progress` ➔ `Resolved`), reducing manual administrative overhead by ~40%.
* **Smart Waste Dispatching:** Streamlined pickup requests and categorization workflows for municipal dispatch units.
* **Responsive Layout:** Clean, accessible user interface optimized for cross-device access.

---

## Tech Stack & Architecture
* **Platform :** [Bubble.io](https://bubble.io) (Full-Stack Visual Development Engine)
* **Database & Data Modeling:** Relational database structures with interconnected tables (`Users`, `Complaints`, `WasteCategories`, `StatusLogs`)
* **Logic & Workflows:** Custom event-driven backend workflows, role-based conditional visibility and state management
